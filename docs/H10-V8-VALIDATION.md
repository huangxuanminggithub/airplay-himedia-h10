# H10 第八版验收记录

验收日期：2026-10-12。公开整理日期：2026-10-18。

## 实机反馈

海美迪 H10 四代 / Android 7，iPhone 14 Pro Max，通过控制中心“屏幕镜像”。使用者确认：

- 第八版未再出现画面和声音同时卡一下。
- 音画同步，延迟正常，体验不错。
- 运动测试页、主屏滑动、连续有声视频和横竖屏切换属于本轮测试场景。

“很丝滑”“同步”“延迟正常”是上述硬件与网络条件下的主观体验，不是精确延迟测量或跨设备保证。

## 自动和日志验证

| 指标 | 记录 |
| --- | --- |
| JVM 回归测试 | 33 项通过 |
| 协议 / 解码器 | H.265 / OMX.hisi.video.decoder.hevc |
| 解码中位数（60 fps 测试段） | 59.98 fps |
| 应用画面提交中位数 | 59.29 fps |
| 系统显示统计中位数 / 范围 | 54.59 / 49.13–57.67 fps |
| 该测试段系统去重显示统计 | 约 53.41 fps |
| 图形追踪中的显示缓冲等待最大值 | 第八版约 6.33 ms；之前记录约 158.67 ms |

前后追踪窗口、输入与采集开销不同，最大等待值对比仅反映所采集片段，不保证所有场景。显示统计包含相互矛盾的期望、就绪和呈现时间戳；没有高速摄影或物理显示测量，不能宣称全程稳定 60 fps。

在抖音镜像的另一段中，发送端时间戳约 29.98 fps，盒子解码、提交与系统显示均约 30 fps。这一段不是收到 60 帧而只显示 30 帧；接收能力上限与手机当时实际发送帧率不同。
